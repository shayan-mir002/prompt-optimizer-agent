# CRISPE

> Capacity-Role-Insight-Statement-Personality-Experiment

## Metadata

- **ID:** crispe
- **Name:** CRISPE
- **Full Name:** Capacity-Role-Insight-Statement-Personality-Experiment
- **Complexity:** advanced
- **Best For:** writing, analysis, coding, creative-writing, problem-solving

## Description

A framework that assigns capacity and role, provides insight, states the task, adds personality, and encourages experimentation.

## Template

```text
Capacity/Role: {{capacity}}
Insight: {{insight}}
Statement: {{statement}}
Personality: {{personality}}
Experiment: {{experiment}}
```

## Variables

| Name | Description | Required |
| ---- | ----------- | :------: |
| capacity | The capacity and role to assume | Yes |
| insight | Background context and information to work with | Yes |
| statement | The specific task or request | Yes |
| personality | The tone, style, and personality to adopt | Yes |
| experiment | What variations or approaches to explore | No |

## Example

```text
Capacity/Role: You are a product strategist at a Series B SaaS company.
Insight: Our NPS dropped from 62 to 41 over the last quarter. Support tickets increased 3x. Users love the core product but report 'death by a thousand papercuts' in the UX.
Statement: Create a prioritized UX improvement roadmap for Q2.
Personality: Be direct and data-driven but empathetic to user pain points.
Experiment: Include one 'wild card' high-risk/high-reward idea alongside practical quick wins.
```

## When to Use

When you need a nuanced, personality-driven response with room for creative exploration.
