# TAG

> Task-Action-Goal

## Metadata

- **ID:** tag
- **Name:** TAG
- **Full Name:** Task-Action-Goal
- **Complexity:** simple
- **Best For:** writing, content-creation, analysis, planning

## Description

Clarifies what needs to be done, how to do it, and why.

## Template

```text
Task: {{task}}
Action: {{action}}
Goal: {{goal}}
```

## Variables

| Name | Description | Required |
| ---- | ----------- | :------: |
| task | What needs to be done | Yes |
| action | How to accomplish it | Yes |
| goal | The desired outcome | Yes |

## Example

```text
Task: Write a blog post about sustainable living.
Action: Cover 5 practical tips with real-world examples.
Goal: Educate readers and inspire them to adopt eco-friendly habits.
```

## When to Use

When you need clarity on what, how, and why. Useful for guiding complex actions with a clear purpose.
