# BROKE

> Background-Role-Objectives-Key results-Evolve

## Metadata

- **ID:** broke
- **Name:** BROKE
- **Full Name:** Background-Role-Objectives-Key results-Evolve
- **Complexity:** moderate
- **Best For:** planning, marketing, productivity, business, project-management

## Description

Sets background, role, objectives, key results, and an iteration step for goal-driven tasks.

## Template

```text
Background: {{background}}
Role: {{role}}
Objectives: {{objectives}}
Key results: {{key_results}}
Evolve: {{evolve}}
```

## Variables

| Name | Description | Required |
| ---- | ----------- | :------: |
| background | Situation and constraints to keep in mind | Yes |
| role | The perspective to work from | Yes |
| objectives | The goals to achieve | Yes |
| key_results | How success will be measured | Yes |
| evolve | How the output should be improved or iterated on | Yes |

## Example

```text
Background: Launching an AI project-management tool for SMBs.
Role: Growth marketer.
Objectives: Generate 100 qualified leads this quarter.
Key results: 30% email open rate, 5% demo conversion.
Evolve: Propose a second iteration if first-week metrics underperform.
```

## When to Use

When a task is goal-oriented and benefits from defining measurable key results and an iteration loop.
