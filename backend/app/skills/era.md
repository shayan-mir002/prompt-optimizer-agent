# ERA

> Expectation-Role-Action

## Metadata

- **ID:** era
- **Name:** ERA
- **Full Name:** Expectation-Role-Action
- **Complexity:** simple
- **Best For:** writing, analysis, productivity, communication

## Description

Defines the expected output, the role to play, and the actions to take.

## Template

```text
Expected output: {{expectation}}
Role: {{role}}
Actions: {{actions}}
```

## Variables

| Name | Description | Required |
| ---- | ----------- | :------: |
| expectation | The desired result and its format | Yes |
| role | The perspective or persona to adopt | Yes |
| actions | The concrete steps to take | Yes |

## Example

```text
Expected output: A 200-word executive summary in markdown.
Role: A data analyst.
Actions: Summarize the key findings, highlight risks, and recommend next steps.
```

## When to Use

When the outcome and the approach matter equally and should be stated explicitly.
