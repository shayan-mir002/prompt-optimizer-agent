# CO-STAR

> Context-Objective-Style-Tone-Audience-Response

## Metadata

- **ID:** co-star
- **Name:** CO-STAR
- **Full Name:** Context-Objective-Style-Tone-Audience-Response
- **Complexity:** advanced
- **Best For:** copywriting, marketing, content-creation, communication

## Description

A comprehensive framework from GovTech Singapore that covers all aspects of effective prompt design.

## Template

```text
Context: {{context}}
Objective: {{objective}}
Style: {{style}}
Tone: {{tone}}
Audience: {{audience}}
Response: {{response}}
```

## Variables

| Name | Description | Required |
| ---- | ----------- | :------: |
| context | Background information and situation | Yes |
| objective | What you want to achieve | Yes |
| style | Writing style to follow | Yes |
| tone | Emotional tone of the output | Yes |
| audience | Who the output is for | Yes |
| response | Desired response format and type | Yes |

## Example

```text
Context: Our fintech app just launched a new budgeting feature.
Objective: Write an announcement email to existing users.
Style: Professional yet approachable, like a trusted financial advisor.
Tone: Excited but not pushy.
Audience: Tech-savvy millennials who already use our app.
Response: A 200-word email with a clear CTA to try the feature.
```

## When to Use

When you need precise control over every aspect of the output, especially for audience-facing content.
