# APE

> Action-Purpose-Expectation

## Metadata

- **ID:** ape
- **Name:** APE
- **Full Name:** Action-Purpose-Expectation
- **Complexity:** simple
- **Best For:** writing, analysis, planning, productivity

## Description

Defines what action to take, why it matters, and what the expected outcome looks like.

## Template

```text
Action: {{action}}
Purpose: {{purpose}}
Expectation: {{expectation}}
```

## Variables

| Name | Description | Required |
| ---- | ----------- | :------: |
| action | The specific action to take | Yes |
| purpose | Why this action matters | Yes |
| expectation | What the result should look like | Yes |

## Example

```text
Action: Write a comprehensive onboarding email sequence for new SaaS users.
Purpose: Reduce churn in the first 30 days by guiding users to their aha moment.
Expectation: 5-email sequence over 14 days with personalized milestones and clear CTAs.
```

## When to Use

When you need to align on what to do, why, and what success looks like.
