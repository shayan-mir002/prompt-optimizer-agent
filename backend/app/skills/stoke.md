# STOKE

> Subject-Task-Output-Key-expectations

## Metadata

- **ID:** stoke
- **Name:** STOKE
- **Full Name:** Subject-Task-Output-Key-expectations
- **Complexity:** simple
- **Best For:** writing, analysis, coding, content-creation, summarization

## Description

A concise framework that defines the subject, task, output, and key expectations.

## Template

```text
Subject: {{subject}}
Task: {{task}}
Output: {{output}}
Key Expectations: {{key_expectations}}
```

## Variables

| Name | Description | Required |
| ---- | ----------- | :------: |
| subject | The subject matter or topic | Yes |
| task | What needs to be done with the subject | Yes |
| output | Desired output format and length | Yes |
| key_expectations | Critical requirements the output must meet | Yes |

## Example

```text
Subject: Recent advances in solid-state battery technology.
Task: Summarize the key breakthroughs from the last 6 months.
Output: A 300-word executive briefing with bullet points.
Key Expectations: Include company names, technical specifics (energy density numbers), and estimated timeline to commercialization.
```

## When to Use

When you need a straightforward, no-frills prompt that covers the essentials quickly.
