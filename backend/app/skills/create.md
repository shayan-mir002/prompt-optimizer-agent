# CREATE

> Characters-Relationship-Environment-Aim-Tone-Extras

## Metadata

- **ID:** create
- **Name:** CREATE
- **Full Name:** Characters-Relationship-Environment-Aim-Tone-Extras
- **Complexity:** advanced
- **Best For:** storytelling, creative-writing, copywriting, marketing

## Description

A storytelling and creative content framework focusing on characters, relationships, and environment.

## Template

```text
Characters: {{characters}}
Relationship: {{relationship}}
Environment: {{environment}}
Aim: {{aim}}
Tone: {{tone}}
Extras: {{extras}}
```

## Variables

| Name | Description | Required |
| ---- | ----------- | :------: |
| characters | Who is involved (people, brands, personas) | Yes |
| relationship | How the characters relate to each other | Yes |
| environment | The setting or context | Yes |
| aim | What needs to be achieved | Yes |
| tone | Emotional register | Yes |
| extras | Additional constraints, themes, or elements to include | No |

## Example

```text
Characters: A burned-out tech CEO and her AI assistant.
Relationship: The AI gradually becomes her most trusted advisor.
Environment: A near-future Silicon Valley startup during a crisis.
Aim: Write a 500-word blog post about AI-human collaboration.
Tone: Reflective and hopeful.
Extras: Include a surprising insight about vulnerability in leadership.
```

## When to Use

When creating narrative content, brand stories, or any output where character dynamics and setting matter.
