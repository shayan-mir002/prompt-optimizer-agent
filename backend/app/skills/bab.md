# BAB

> Before-After-Bridge

## Metadata

- **ID:** bab
- **Name:** BAB
- **Full Name:** Before-After-Bridge
- **Complexity:** simple
- **Best For:** copywriting, marketing, storytelling, change-management

## Description

Describes a current problem, paints a vision of the future, and provides a bridge to get there.

## Template

```text
Before: {{before}}
After: {{after}}
Bridge: {{bridge}}
```

## Variables

| Name | Description | Required |
| ---- | ----------- | :------: |
| before | The current problematic situation | Yes |
| after | The desired future state | Yes |
| bridge | How to get from before to after | Yes |

## Example

```text
Before: Our customer support team spends 3 hours daily answering repetitive questions.
After: 80% of inquiries are resolved instantly by AI, freeing the team for complex issues.
Bridge: Implement an AI chatbot trained on our top 200 FAQs with human handoff for edge cases.
```

## When to Use

When making a case for change, pitching an idea, or telling a transformation story.
