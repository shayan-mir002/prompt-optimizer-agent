# COAST

> Context-Objective-Actions-Signals-Tone

## Metadata

- **ID:** coast
- **Name:** COAST
- **Full Name:** Context-Objective-Actions-Signals-Tone
- **Complexity:** moderate
- **Best For:** planning, strategy, writing, content-creation

## Description

A clear framework that sets context, defines the objective, outlines actions, sets success signals, and establishes tone.

## Template

```text
Context: {{context}}
Objective: {{objective}}
Actions: {{actions}}
Signals: {{signals}}
Tone: {{tone}}
```

## Variables

| Name | Description | Required |
| ---- | ----------- | :------: |
| context | The situation or background | Yes |
| objective | What you want to achieve | Yes |
| actions | The actions to take | Yes |
| signals | How to measure success | Yes |
| tone | The tone for the output | Yes |

## Example

```text
Context: We're pivoting from B2C to B2B and need to reposition our brand.
Objective: Create a brand messaging guide for the sales team.
Actions: Define new value propositions, rewrite elevator pitch, create objection-handling scripts.
Signals: Sales team can independently pitch to enterprise clients within 2 weeks.
Tone: Authoritative but approachable. Think 'trusted advisor' not 'pushy salesperson'.
```

## When to Use

When you need a structured plan with measurable outcomes and a consistent voice.
