# AIDA

> Attention-Interest-Desire-Action

## Metadata

- **ID:** aida
- **Name:** AIDA
- **Full Name:** Attention-Interest-Desire-Action
- **Complexity:** moderate
- **Best For:** copywriting, marketing, sales, advertising, content-creation

## Description

Classic marketing framework structured to capture attention, build interest, create desire, and drive action.

## Template

```text
Attention: {{attention}}
Interest: {{interest}}
Desire: {{desire}}
Action: {{action}}
```

## Variables

| Name | Description | Required |
| ---- | ----------- | :------: |
| attention | The hook or headline that grabs attention | Yes |
| interest | Content that builds curiosity and engagement | Yes |
| desire | Emotional or logical appeal that creates want | Yes |
| action | The specific call to action | Yes |

## Example

```text
Attention: 'Your team wastes 11 hours a week on meetings that should've been emails.'
Interest: 'We analyzed 50,000 calendar entries across 200 companies. The pattern is clear: unstructured meetings are the #1 productivity killer.'
Desire: 'Imagine getting those 11 hours back every week. That's 26 full workdays a year to actually build things.'
Action: 'Start your free 14-day trial. No credit card required. Setup takes 2 minutes.'
```

## When to Use

Anytime you're creating marketing copy, sales content, landing pages, or any persuasive writing.
