# CARE

> Context-Action-Result-Example

## Metadata

- **ID:** care
- **Name:** CARE
- **Full Name:** Context-Action-Result-Example
- **Complexity:** moderate
- **Best For:** writing, content-creation, coding, analysis

## Description

Provides context, specifies the action, defines the desired result, and gives an example.

## Template

```text
Context: {{context}}
Action: {{action}}
Result: {{result}}
Example: {{example}}
```

## Variables

| Name | Description | Required |
| ---- | ----------- | :------: |
| context | Background situation or constraints | Yes |
| action | What needs to be done | Yes |
| result | Desired outcome | Yes |
| example | A concrete example of the expected output | Yes |

## Example

```text
Context: We're a startup launching our MVP in 2 weeks. Our landing page currently has a 2% conversion rate.
Action: Rewrite the hero section copy to increase conversions.
Result: Clear value proposition in under 10 words, a compelling CTA, and social proof.
Example: 'Ship features 10x faster with AI-powered code review. Start free → Trusted by 2,000+ dev teams.'
```

## When to Use

When providing context helps produce better, more targeted results and an example accelerates understanding.
